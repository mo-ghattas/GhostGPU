# Phase-one validation, 18 October 2026

The v0.2.0 expansion adds 25 point/vector and 9 fixed-topology mesh components. Existing component GUIDs are unchanged.

Environment: Windows x64, Rhino/Grasshopper 8.35.26251.13001, .NET 8 validation and .NET Framework 4.8 plug-in build, NVIDIA GeForce RTX 3050 Ti Laptop GPU (4 GiB), NVIDIA driver 617.14. ILGPU/ILGPU.Algorithms remain pinned to 1.5.3.

The new numerical tests include empty/repeat-last batches, wrong-kind and foreign-session rejection, large-vector angles, subnormal division, compact far-origin points, warped quad areas, isolated vertices, invalid GPU face/CSR indices, allocation rollback, and repeated affine transforms across staging streams.

Transfer counters verify no intermediate geometry downloads through the expanded point/vector and mesh transform chains. Device topology safety checks read back a four-byte status flag per check. This is explicitly separate from geometry readback; mesh topology preprocessing/uploads and preview/readback costs remain.

Reproduce with `scripts/Test.ps1 -Backend both`, then `scripts/TestHost.ps1 -Backend both`. Runtime machine-readable reports and icon/contact-sheet artifacts are generated under `artifacts/`; they are excluded from Git. Add `-WriteExample` to the host command to regenerate `examples/GhostGPU-Phase1.gh`.

These are bounded correctness checks. The small example is not a speedup benchmark, and the expansion does not establish arbitrary native component equivalence. Topology-changing meshing, spatial queries and later geometry milestones remain outside this pack. The pre-existing K3–K5 issues remain documented in [known issues](../KNOWN-ISSUES.md).
